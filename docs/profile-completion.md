# 통합 계정 정보 보완

일반 사용자는 로그인 후 이름·조직·팀·직급·이메일에 빈 값 또는 `미지정`이 있으면 입력 팝업을 봅니다. `나중에 입력`으로 닫으면 현재 탭의 세션에서는 자동 안내를 반복하지 않습니다. 상단 `내 계정`에서는 언제든 다시 열 수 있습니다. 관리자는 자동 안내에서 제외됩니다.

`/login?profile=complete&next=%2Fwiameet%2Fagent`는 저장된 로그인 세션을 사용해 팝업을 명시적으로 열고, 저장 완료 확인 후 WiaMeet로 돌아갑니다. 미로그인 시 먼저 로그인합니다. 초기 비밀번호 변경은 정보 보완보다 우선합니다. 복귀 URL은 기존 safeDestination 검증을 사용합니다.

`POST /api/auth/profile/complete`는 로그인 및 기존 CSRF 검증을 적용합니다. 요청에는 누락된 프로필 필드만 전달합니다. 이미 등록된 필드 변경은 409, 미입력 필드나 허용하지 않은 필드는 422로 거절합니다. 계정 식별자·비밀번호·관리자 권한은 수정할 수 없습니다. 사용자 행 잠금과 가입 API의 공통 디렉터리 잠금으로 동시 저장을 보호합니다. 디렉터리 이름은 기존 항목과 정규화 비교하고, 없는 이름은 가입 화면과 동일하게 생성합니다.

추천 입력은 조직·팀·직급만 제공하며 `미지정`을 제외합니다. 이름과 이메일은 추천하지 않습니다. WiaMeet에서는 기존 팀-워크스페이스 매핑 로직을 그대로 사용합니다.

검증: `python -m unittest backend.tests.test_profile_completion`. 개발 서버의 임시 계정으로 인증/CSRF/필수 항목/기존 필드 변경 차단 및 실제 로그인→팝업→저장→WiaMeet 복귀를 확인했습니다. 관리자 자동 안내 제외와 1280/1440/1920 화면도 확인했습니다. `test_id`의 조직·팀·직급 NULL 값은 유지했습니다.
